# Vigil

Vigil is a landing page for a product concept focused on making important alerts and follow-ups harder to miss.

This repository contains only the public-facing landing page code for Vigil. The actual working product code, backend logic, private implementation details, and production system are not included in this repository.

## What Is Included

- Static landing page markup
- Styling and front-end interactions
- Image and font assets used by the landing page
- Visual verification assets used while refining the page

## What Is Not Included

- Actual product source code
- Backend services
- Authentication, database, or API logic
- Private business logic or production infrastructure

## Project Structure

```text
.
├── index.html
├── styles.css
├── assets/
├── verification/
└── *.js
```

## Viewing Locally

Open `index.html` in a browser to view the landing page.
